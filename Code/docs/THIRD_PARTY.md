# Third-party resources

The MIT license applies to the custom code in this repository. MATLAB, SPM12, DPABI, HCPex, Python dependencies and external model weights retain their respective licenses.

HCPex provides the anatomical parcellation. The included parcel crosswalk defines the bilateral study ROIs. SPM12 supplies fMRI model estimation and NIfTI operations; DPABI supplies the preprocessing framework. Atlas NIfTI files and software installations are supplied through study_config.m.

Street-view imagery and participant datasets follow their applicable data-use terms. Citation metadata for the study code are provided in CITATION.cff.
